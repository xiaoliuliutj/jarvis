# Jarvis UI 设计规格文档

## 项目简介

Jarvis 是一个桌面 AI 助手应用，基于 Electron 构建，支持多端接入（PC 界面直接对话、微信消息接入）。界面是自定义无边框窗口，默认尺寸 960×680px，可缩放，最小 640×480px。

---

## 整体布局

```
┌─────────────────────────────────────────────────────────────┐
│  标题栏（38px 高，可拖拽移动窗口）                              │
│  左：✦ Jarvis 图标 + 名称                右：⚙ 设置 ─ ✕      │
├──────────────┬──────────────────────────────────────────────┤
│              │  顶部：工作目录栏（可隐藏）                     │
│   左侧        │                                              │
│   会话侧边栏  │  中间：消息滚动区（主要内容区域）                │
│   （220px）   │                                              │
│              │  底部：输入框 + 发送按钮                        │
└──────────────┴──────────────────────────────────────────────┘
```

**设置面板**：点击标题栏⚙齿轮按钮后，从右侧滑入覆盖在对话区上方（overlay，不占固定布局空间）。再次点击或点外侧关闭。

---

## 各区域说明

### 1. 标题栏
- 高度：38px，背景最深色
- 左侧：应用图标（小符号）+ "Jarvis" 文字
- 右侧按钮（从左到右）：设置⚙、最小化─、关闭✕
- 整条可拖拽移动窗口；按钮区域不可拖拽

### 2. 左侧会话侧边栏（宽 220px）
顶部有「＋ 新建会话」按钮，下方是会话列表，支持滚动。

**会话条目分组（从上到下）**：
1. **★ 主会话**（PC 端，始终存在，不可归档）
2. **微信会话列表**（通过微信接入的对话，标注来源图标 💬 WEIXIN）
3. **分隔线**
4. **普通会话**（PC 端手动新建的临时会话）
5. **归档会话**（折叠，点展开按钮展开）

**会话条目内容**：
- 一个小圆点（状态指示）
- 会话名称（从对话第一条消息自动命名）
- 时间戳（最后活跃时间，如"11/16 22:59"）
- 鼠标悬停时显示归档按钮🗂（普通会话才有）

**激活状态**：左侧竖线高亮 + 条目背景高亮。主会话圆点和名称颜色与普通会话不同（暖色）。

**只读标记**：微信会话条目上有🔒小图标，输入框区域显示"该会话只能通过 weixin 回复"提示条。

### 3. 顶部工作目录栏
- 高度约 32px，默认显示
- 显示当前会话绑定的工作目录路径（以标签形式，可点击 ✕ 移除）
- 右侧有「＋ 添加目录」按钮（弹出系统文件夹选择器）
- 无绑定目录时也显示（只有添加按钮）

### 4. 消息区（主体）
消息从上往下排列，支持滚动，新消息出现在底部。

**消息类型**：

| 类型 | 位置 | 外观 |
|------|------|------|
| 用户发送（PC） | 右对齐 | 深色气泡 |
| AI 回复（PC） | 左对齐 | 较深气泡，左侧有 accent 色竖线 |
| 微信用户发送 | 右对齐 | 与 PC 用户气泡相同外观，气泡上方有小字 `[💬 weixin] 用户ID` |
| 微信 AI 回复 | 左对齐 | 与 PC AI 气泡相同外观，气泡上方有小字 `[Jarvis → 💬 weixin]` |
| 工具调用折叠块 | 左侧 | `▶ N 个工具调用`，可点击展开，展开后显示各工具的调用详情 |
| 错误消息 | 左对齐 | 红色边框气泡，前缀 ⚠️ |
| 系统提示 | 居中 | 小字灰色胶囊形状 |
| AI 思考中 | 左侧 | "Jarvis 思考中" + 三个跳动圆点 |

**工具调用标签**（折叠块内）：
- 单行标签，显示工具名和参数预览
- 字体用等宽字体（代码字体）
- 前缀有小图标 ⚙

### 5. 底部输入区
- 多行文本框（自适应高度，最高 120px）
- 占位提示："输入消息，Shift+Enter 换行，Enter 发送…"
- 右侧发送按钮，正常状态显示"发送"，AI 处理中显示"运行中…"且不可点击
- 只读模式（查看微信会话）：输入框和按钮禁用，顶部显示提示条

### 6. 设置面板（overlay，从右侧滑入）
宽约 240px，从标题栏下方覆盖在界面右侧。内容：
- **当前模型**：显示模型名（可点击弹出配置文件编辑器）
- **权限模式**：下拉选择（bypass / acceptEdits / rulesOnly 等）
- **记忆事件日志**：最近的文件操作/记忆写入事件（最多 20 条）
- **累计轮次/成本**：数字统计

---

## 弹窗：配置文件编辑器

点击设置面板中的"当前模型"触发。全屏遮罩 + 居中弹窗，内含：
- 顶部：标题"编辑配置文件" + 文件路径 + 关闭按钮
- 中间：JSON 文本编辑器（等宽字体，可滚动）
- 底部：错误提示 + 取消/保存按钮

## 交互行为

### 会话切换
- 点击左侧条目，中间消息区清空并重新渲染目标会话的历史
- 切换时保留当前会话的滚动位置

### 新建会话
- 点击「＋ 新建会话」，消息区清空，等待用户发送第一条消息
- 第一条消息发出后，AI 回复结束，会话自动命名（取第一条用户消息），出现在侧边栏

### 微信消息实时同步
- 用户在手机微信发消息 → 立刻在界面对应的微信会话里显示用户气泡 + "处理中"指示器
- AI 回复完成 → 显示 AI 气泡，更新会话时间戳，刷新侧边栏排序

### 工具调用折叠
- AI 在处理过程中调用工具时，工具调用标签在消息区实时出现
- AI 最终回复到达后，所有中间过程自动收进折叠块（`▶ N 个工具调用`）
- 折叠块持久保存，重启/切换会话后仍可展开查看

### 归档
- 点击会话条目悬停出现的🗂归档按钮
- 会话移至归档区，自动生成摘要写入长期记忆
- 归档后自动切换回主会话

## 数据来源

| 功能 | 技术 |
|------|------|
| PC AI 对话 | Electron IPC → agent.mjs → Claude API |
| 微信消息收发 | Bridge Server（Node.js HTTP+WS）→ 微信 iLink Bot API |
| 实时事件推送 | WebSocket 7780 端口广播 |
| 会话历史持久化 | 本地 `.messages.jsonl` 文件 |
| 长期记忆 | `long-term.jsonl` + `config/global.md` |
| 定时任务 | `config/bridge.json` 里的 crons 配置（如每天早上发早报） |
