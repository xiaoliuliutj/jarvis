登录 Jarvis

账号 + 密码登录。注册需要填写昵称，账号唯一；昵称和密码不做唯一性限制。

已有账号请直接登录；注册新账号会创建独立数据，不会继承原会话。

连接 Jarvis

手机先连上 Tailscale，再填入电脑端 Bridge 的地址。登录后会自动保存用户 token。

添加模型

整段 JSON 会加密保存，不拆分字段；兼容 Claude Code settings 格式（env.ANTHROPIC_* / model）。编辑时留空表示保持原配置。

对话模型直接粘贴 JSON；图片/视频/语音模型先保存配置，执行适配在下一阶段。
