添加模型

整段 JSON 会加密保存，不拆分字段；兼容 Claude Code settings 格式（env.ANTHROPIC_* / model）。编辑时留空表示保持原配置。

对话模型直接粘贴 JSON；图片/视频/语音模型先保存配置，执行适配在下一阶段。
